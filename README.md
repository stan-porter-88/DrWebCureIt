## 📖 About

Dr.Web CureIt is built by Doctor Web, a security vendor that has shipped antivirus tooling since the early 1990s. This utility is a single executable scanner: you run it, it checks memory, startup items, system areas and files against the current Dr.Web signature base plus heuristics, and it can neutralise threats it detects. Because it does not install a resident service, it is often used as a second opinion scan or as a first response tool on a machine that already behaves strangely. Current builds ship an updated detection engine, faster scanning of large archives and a refreshed quarantine handling flow.

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Scan stops at a specific file | Note the path in the log, exclude it temporarily and rerun the scan on the remaining drives. |
| Scanner closes at launch | Check that the executable is fully downloaded, redownload if the file size looks smaller than expected. |
| Detection list looks empty after a scan | Confirm the signature base updated at startup and rerun a full scan rather than a quick check. |
| Another antivirus flags the scanner | Add the Dr.Web CureIt executable to that product's exclusion list and relaunch. |
| Removable drive not scanned | Eject and reconnect the device, then select it explicitly in the custom scan scope. |
| Report file will not open | Save the log to a plain folder path without special characters and open it with Notepad. |
